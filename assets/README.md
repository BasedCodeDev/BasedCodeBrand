# BasedCode brand assets

This folder contains first-version supporting assets for the brand bible.

- `basedcode-wordmark.svg` — provisional wordmark exploration.
- `colour-swatches.svg` — core palette reference.
- `vendor/text-ripple.js` — vendored copy of [BasedCodeDev/text-ripple-js](https://github.com/BasedCodeDev/text-ripple-js), used for signature text transitions.
- `vendor/text-ripple-LICENSE.txt` — MIT licence notice for the vendored ripple library.

The assets are intentionally simple and editable. The wordmark is a v1 exploration, not a replacement for a professionally drawn logo if a final identity project follows.
